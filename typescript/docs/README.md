# Prajapatt TypeScript SDK documentation

- [Getting started](getting-started.md): install, configure a client, and make
  a chat request.
- [API reference](api-reference.md): client methods, request options, streaming,
  and exceptions.

This SDK calls the Prajapatt HTTP API. It does not train or run the model.
The current API supports text chat; streaming sends response chunks after
inference has completed, rather than generating tokens live.
